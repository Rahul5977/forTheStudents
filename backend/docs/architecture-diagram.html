3  Low-Level Design — two core flows

The hottest read path, and the booking↔payment saga.

Predictor (cache path)

Frontend: GET /predict?rank,cat,home,filters
↓
CloudFront edge cache
HIT → shared slice, <50 ms
↓ miss
Predictor λ (warm snapshot in memory)
↓
Redis snapshot vN → filter + bucket (Safe/Target/Reach)
cache slice (SWR) & return

Booking ↔ Payment saga

Student → Booking: POST /bookings (idempotencyKey)
↓
Booking: PENDING_PAYMENT + slot hold (TTL auto-release)
↓
Payments → Razorpay: create order → pay (UPI/card)
↓
Razorpay webhook (signed): captured → append ledger
↓
Payments → EventBridge: payment.succeeded
↓
Booking: CONFIRMED → notify both + calendar
